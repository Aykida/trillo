# Trillo — Hotel Booking App UI

A responsive hotel booking web app UI built with Sass (SCSS), following BEM methodology.

## Features
- Responsive layout using CSS Flexbox
- CSS Custom Properties (variables) for theming
- BEM naming convention
- SVG sprite icons
- Media queries for mobile/tablet/desktop views

## Built With
- HTML5
- Sass / SCSS
- CSS (Flexbox, Custom Properties)
